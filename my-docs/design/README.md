# Design corpus — Refero notes and visual references

Drop design research here: Refero.design notes, screenshots-worth-of-words,
teardown notes on interfaces you liked, and design principles worth keeping.
Any markdown file in this folder becomes research context (hybrid `DOC_PATH`
loading) on the next deploy — the researcher can then answer "how do the
best products present X?" with our own curated references first.

## Suggested format per note

```markdown
# <Product / pattern> — <one-line takeaway>

- Source: refero.design link or product URL
- Pattern: onboarding / pricing page / empty state / search / ...
- Why it works: the mechanism, not the aesthetics
- Rhyme for us: how this maps to Nursing Mastery / the Brain UI
```

## Workflow

1. Browsing Refero and something clicks? Paste the link + three lines here.
2. Commit (or ask any agent to commit it for you).
3. Ask the researcher: "Check the design corpus — what patterns did we save
   for onboarding flows?"
