Retriever Plugins

GPT Researcher can use a search provider that ships as its own Python package. Install the package, set RETRIEVER to the name it registers, and it is used like any built-in retriever. No change to GPT Researcher is needed.

This is the recommended way to add a new search provider. The core project keeps a small set of built-in retrievers; a plugin lets a provider ship, version and support its integration on its own schedule.

Using a plugin​

pip install gptr-acme-retriever
export RETRIEVER=acme

Plugins can be combined with built-in retrievers, e.g. RETRIEVER=acme,duckduckgo. Built-in names always take precedence, so a plugin cannot replace tavily, google or any other shipped retriever.

Community retrievers​

These plugins are distributed and maintained separately from GPT Researcher. Install them in the same Python environment as GPT Researcher.

Autom​

Autom is a SERP API: it runs the search on Google, Bing, Brave, DuckDuckGo or Yahoo at the time of the call and returns the results as JSON.

pip install gpt-researcher-autom
export RETRIEVER=autom
export AUTOM_API_KEY="your-autom-api-key"

Get an API key at app.autom.dev. Optional setting:

  • AUTOM_ENGINE: google (default), bing, brave, duckduckgo or yahoo.
  • Combine with a built-in retriever, e.g. RETRIEVER=autom,duckduckgo.

The retriever returns links with their title and snippet, and GPT Researcher scrapes each page (requires_scraping=True). Domains in query_domains are added to the query as site: filters. On a missing key or a failed request it logs a warning and returns no results, so one failing provider does not stop a research run.

See the plugin documentation for details. API access and integration support are provided by Autom.

cloro​

cloro returns live Google and Bing results and AI answers with their sources. The package registers four retrievers:

  • cloro: Google organic results (about 10 per search). GPT Researcher scrapes each page.
  • cloro_bing: Bing organic results (one page per search). GPT Researcher scrapes each page.
  • cloro_aimode: the Google AI Mode answer under raw_content, then the sources it cites.
  • cloro_bing_aimode: the Bing AI Mode answer under raw_content, then the sources it cites.
pip install gpt-researcher-cloro
export CLORO_API_KEY="your-cloro-key"
export RETRIEVER=cloro            # or cloro_bing, cloro_aimode, cloro_bing_aimode

Get an API key at dashboard.cloro.dev. CLORO_COUNTRY sets the country (default US). Each search is one cloro request and costs credits on the user's cloro plan. Requires GPT Researcher 0.16.1+. See the plugin README for the result shapes and limits. Support is provided by the plugin maintainer.

Keenable​

pip install gpt-researcher-keenable, then set RETRIEVER=keenable. It works without an API key; KEENABLE_API_KEY is optional.

Piloterr​

Piloterr is a web data API that runs Google searches on its own infrastructure and returns the results as JSON.

pip install gpt-researcher-piloterr
export RETRIEVER=piloterr
export PILOTERR_API_KEY="your-piloterr-api-key"

Get an API key at app.piloterr.com. Combine it with a built-in retriever, e.g. RETRIEVER=piloterr,duckduckgo.

The retriever returns links with their title and snippet, and GPT Researcher scrapes each page (requires_scraping=True). Domains in query_domains are added to the query as site: filters. On a missing key or a failed request it logs a warning and returns no results, so one failing provider does not stop a research run.

See the plugin documentation for details. API access and integration support are provided by Piloterr.

Sciverse​

Sciverse retrieves scientific literature passages and resolves citation links through its metadata API. Requires Python 3.12+ and GPT Researcher 0.16.1+ (installed as a package dependency).

pip install gpt-researcher-sciverse
export RETRIEVER=sciverse
export SCIVERSE_API_TOKEN="your-sciverse-token"

Obtain an API token at sciverse.space. Optional settings:

  • SCIVERSE_MODE: fast for keyword retrieval, balanced (default) for hybrid keyword/vector retrieval, or quality for hybrid retrieval with query rewriting.
  • SCIVERSE_BASE_URL: defaults to https://api.sciverse.space.
  • Combine with a built-in retriever, e.g. RETRIEVER=sciverse,duckduckgo.

Results provide already-retrieved passages under raw_content, together with available titles and abstracts. These are excerpts, not complete papers. The plugin declares requires_scraping=False so this evidence is used directly rather than fetching the citation's publisher page. It accepts query_domains for interface compatibility but does not apply domain filtering.

See the plugin documentation for configuration and development details. API access and integration support are provided by the plugin maintainer.

SpecStream​

SpecStream answers each research sub-query from the live web through its Search API and returns every result with its source.

pip install gpt-researcher-specstream
export RETRIEVER=specstream
export SPECSTREAM_API_KEY="your-specstream-key"

Create an API key at specstream.ai. Optional settings:

  • SPECSTREAM_EXTRACT: set to true to read the top results through the SpecStream Extract API and hand GPT Researcher their text.
  • SPECSTREAM_BASE_URL: defaults to https://api.specstream.ai.
  • Combine with a built-in retriever, e.g. RETRIEVER=specstream,duckduckgo.

See the plugin documentation for configuration details. API access and integration support are provided by the plugin maintainer.

Writing a plugin​

A plugin is a class with the same shape as the built-in retrievers, registered under the gpt_researcher.retrievers entry-point group.

# acme_retriever/__init__.py
import os
import requests

from gpt_researcher.retrievers.base import BaseRetriever


class AcmeSearch(BaseRetriever):
    # True: results are links that GPT Researcher should scrape.
    # False: results already carry the page text under "raw_content".
    requires_scraping = True

    def __init__(self, query, query_domains=None):
        self.query = query
        self.query_domains = query_domains or []
        self.api_key = os.environ["ACME_API_KEY"]

    def search(self, max_results=7):
        try:
            response = requests.get(
                "https://api.acme.example/search",
                params={"q": self.query, "limit": max_results},
                headers={"Authorization": f"Bearer {self.api_key}"},
                timeout=20,
            )
            response.raise_for_status()
            items = response.json().get("results", [])
        except (requests.RequestException, ValueError):
            return []
        return [
            {"href": item["url"], "body": item.get("snippet", "")}
            for item in items
            if item.get("url")
        ]
# pyproject.toml
[project]
name = "gptr-acme-retriever"
version = "0.1.0"
dependencies = ["gpt-researcher", "requests"]

[project.entry-points."gpt_researcher.retrievers"]
acme = "acme_retriever:AcmeSearch"

The entry-point name (acme above) is the value users put in RETRIEVER.

The contract​

  • __init__(self, query, query_domains=None) receives the sub-query and any domain filter.
  • search(self, max_results=7) returns a list of dicts. Each needs a URL under href (or url) and may carry a short body snippet.
  • Set requires_scraping = False only if every result includes the full page text under raw_content; GPT Researcher will then use it without fetching the page.
  • Return [] on network or parsing errors instead of raising, so one failing provider does not abort a research run.

If a plugin fails to import, GPT Researcher logs a warning and falls back to the default retriever. Use the snippet in Testing your Retriever to check your results.
